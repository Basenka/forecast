# Weather Forecast Dashboard

Angular application displaying weather forecast and historical weather data for London using Open-Meteo API.

## Features

- Weather forecast and historical weather data
- Sortable and filterable table
- Temperature line chart
- Heat Index Calculator
- Historical date range selection

## Technologies

- Angular
- PrimeNG
- Chart.js
- Open-Meteo API

## Run Project

Install dependencies:

```bash
npm install
```

Run application:

```bash
ng serve
```

Open:

```txt
http://localhost:4200
```

## API

Weather data provided by:

https://open-meteo.com/
